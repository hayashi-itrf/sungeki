# 利用の手引き

## 最初の作品

1. 「作品・ファイル」から新規作品を作成します。
2. 「制作ツール」から画像・文字・図形を追加し、タイムラインで配置します。
3. プレビューの「再生」またはSpaceキーで再生します。Spaceをもう一度押すと一時停止します。入力欄・ボタン・ダイアログのSpaceはその部品の操作を優先します。
4. 「作品を保存」で編集可能な作品ファイルを保存します。動画の書き出しとは別の操作です。
5. 必要な実行環境を設定し、「動画を書き出す」で動画を作成します。

作品ファイルだけを移しても、参照素材や保存時点の履歴が付属するとは限りません。別の場所へ持ち出す場合は「素材をまとめて保存」を利用してください。別作品を開くと再生位置は先頭になります。

## 音声と素材

セリフは音声合成後に編集再生できます。未合成のセリフは字幕のみであることを画面に表示します。合成エンジンとモデルは別途用意し、設定を登録してください。エンジンごとに利用条件・必要なクレジットが異なります。

試聴音量は作品の音量とは別です。プレビューで下げても、書き出す動画の音量は変わりません。試聴音量は再起動後も復元されます。動画のBGM・セリフの音量は各クリップや全体音量の設定で調整してください。

VRMクリップを選び「姿を見ながらポーズを編集」から関節角度を調整します。「ポーズを適用」で確定し、取消では変更しません。確認時刻、拡大、左右・上下の視点を変更できます。確認用の視点は動画の構図には反映しません。

見た目の調整は項目に応じて即時反映します。開始時刻・長さ・本文などは「変更を適用」でまとめて確定します。未適用の編集がある場合は画面の案内に従ってください。

## 制限

- 簡易プレビューと正式出力では文字組み・ぼかし・最終音量処理などが異なる場合があります。完成映像は確認用動画または正式出力で確認してください。
- 初回の素材読込には時間がかかります。長いVRMのシークでは移動先までの物理計算が必要です。
- すべてのVRM/VRMA、音声エンジン、長時間作品の同期・性能を検証済みではありません。
- 原本がない状態では、軽量表示ができても正式出力できない場合があります。
- 配布証明書による署名・公証や、別のMacでの初回導入の総合確認は完了していません。

素材の規約・クレジット・保存先の空き容量を確認し、大事な作品と素材はバックアップしてください。
