# AivisSpeech / COEIROINK のローカル連携

## 導入と配置

音声エンジンとモデルは同梱しません。まず[初回導入](../README.md#初めて使うときの順序macosのローカル検証版)で動画制作環境を用意し、使いたいエンジンだけを公式配布元から導入してください。全6種類を入れる必要はありません。

| エンジン | 公式入手先 | 検証版 / 自動起動に指定する実行ファイル |
|---|---|---|
| VOICEVOX | [公式サイト](https://voicevox.hiroshiba.jp/) | エンジンの実行ファイル（アプリのアイコンではありません） |
| AivisSpeech | [Engine配布](https://github.com/Aivis-Project/AivisSpeech-Engine/releases/tag/1.2.0) | 1.2.0 macOS-arm64 の展開先にある `run` |
| COEIROINK | [公式ダウンロード](https://coeiroink.com/download) | 2.13.0 macOS ARM64 の `COEIROINKv2.app/Contents/MacOS/engine/engine` |

配布物は一式のまま保管し、実行ファイルだけを抜き出さないでください。パスは利用者の配置先に合わせます。COEIROINKの初期話者はアプリ内の `Contents/MacOS/speaker_info` にあります。AivisSpeechのモデルは公式の案内に従って追加します。モデル保存先はエンジン側の管理で、Sungekiの保存先設定では移動しません。

初めての場合は、公式アプリを手動で起動して声を利用できることを確認し、Sungekiの実行ファイル欄を空欄のまま接続する方法でも使えます。自動起動を使う場合は手動起動したエンジンを終了してから設定してください。自動起動はmacOSのアクセス許可・モデル導入を代行しません。

## 操作

1. 「設定」→「動画制作の実行環境」で、外部ディスクの保存フォルダーと音声エンジンの実行ファイルを設定して保存する。空欄の場合はエンジンを手動で起動する。
2. キャラクター登録でAivisSpeechまたはCOEIROINKを選び、話者一覧を取得する。自動起動を設定済みなら、停止中のエンジンを起動して準備完了まで待つ（最大600秒）。
3. 声を選び、表示される話者の利用条件を確認する。作品内の名前とクレジットを登録する。
4. 通常の音声クリップを作り、音声合成画面から生成する。未生成の音声を順に生成する操作にも対応する。
5. 話速・声の高さ・音量・前後の無音を音声設定で調整できる。AivisSpeechは感情表現・テンポの緩急、COEIROINKは抑揚を別の設定として扱う。

標準接続先は `http://127.0.0.1:10101/` / `http://127.0.0.1:50032/`。
音声合成の接続設定で変更できる。接続先は作品ファイルに保存しない。
出力は44.1kHz・モノラルWAVを要求し、実際のWAVを検証してから共通editorで作品に反映する。
発音辞書・明示した読み・字幕の区別、保存、Undo、口パク解析は既存の共通経路を利用する。

AivisSpeech・COEIROINKは現段階では一括制作レシピ `build_video` に未対応。
既存作品の音声クリップの合成と、その後の通常の動画出力を使用する。
エンジンの自動インストールは含めない。VOICEVOX・AivisSpeech・COEIROINKは実行ファイルの設定により自動起動できる。Sungekiが起動したエンジンは再利用のためホスト終了まで維持し、終了時に所有するプロセス群だけを停止する。他のアプリが起動したエンジンは停止しない。起動中に接続先を変える場合はSungekiを終了してから変更する。COEIROINKは固定ポート50032、他2種は127.0.0.1の指定ポートを使用する。

SBV2・Qwen・Irodoriは従来の起動プロファイルで合成ごとに起動と停止を管理する。全6エンジンとも起動管理に対応するが、保持期間は異なる。自動起動設定は作品ではなくこのMacの実行環境に保存される。

## 開発検証用の所有セッション

`SUNGEKI_RUNTIME_ROOT` を外部ディスクの検証用フォルダーに設定する。
`aivis_ctl.sh start` / `coeiroink_ctl.sh start` は前景で所有セッションを維持する。
別の端末から同じスクリプトの `wait`、利用終了後に `stop`、`status` を実行する。
`STOPPED` を確認するまでは停止成功としない。他のアプリが使用中のポートには接続・終了しない。

配置先の指定は必須。`SUNGEKI_VENDOR_ROOT`（上表の版別フォルダーを置く場所）、または `SUNGEKI_AIVIS_ENGINE` /
`SUNGEKI_COEIROINK_ENGINE` に実行ファイルの絶対パスを指定できる。
COEIROINKのこの配布版は開発スクリプトからポートを変更せず50032を使う。
管理セッションを閉じても、自分が起動した子プロセスだけを終了する。

## 利用条件と検証範囲

Sungeki本体のMITライセンスと、外部エンジン・モデル・音声の条件は別。
[AivisSpeech Engine](https://github.com/Aivis-Project/AivisSpeech-Engine) はLGPL-3.0。
モデルごとの条件は選択した声のpolicyで確認する。
[COEIROINKの利用規約](https://coeiroink.com/terms) と話者別規約を両方確認する。
つくよみちゃんの音声を使用する作品には `COEIROINK:つくよみちゃん` 等の表示が必要。

接続確認ではエンジン版と話者カタログのダイジェストを固定し、実行直前にも比較する。
エンジンのHTTP APIが公開しないモデル重みのバイト単位の同一性を保証するものではない。
タイムアウト・通信切断時はエンジン処理の終了を推定せず、既存の資源保留処理に渡す。

実機・実合成の実施結果は `implementation-status.md` と対応するevidenceを参照。
