# 初回導入（macOS Apple Silicon）

ビルド済みのSungeki.appが起動できている方は、アプリのビルドや開発ツールの導入は不要です。動画出力に必要な設定は次の4項目です。

## 最初の動画を出す

1. **FFmpegとFFprobeを用意します。** [FFmpeg公式の入手案内](https://ffmpeg.org/download.html)からmacOS用の実行ファイルを入手します。Homebrewを既に利用している場合は `brew install ffmpeg` で両方を導入できます。各導入方法が要求する開発ツールは、その配布元の案内に従ってください。
2. **外部ディスクに専用の保存フォルダーを作ります。** 例は `/Volumes/動画用SSD/Sungeki/runtime` です。実際のディスク名を使い、アプリ使用中は接続してください。
3. **「設定」→「動画制作の実行環境」→「保存済み設定を読み込む」を開きます。** 下表の4項目を指定して保存します。
4. **文字・図形を置いた短い作品で「動画を書き出す」を試します。** 「正式な画像を確認」は任意の確認です。毎回先に実行する必要はありません。「作品を保存」は編集データの保存であり、MP4出力とは別です。

| 設定項目 | 指定するもの |
|---|---|
| 外部ディスクの保存フォルダ | 作成した専用フォルダー |
| FFmpeg | FFmpegの実行ファイル |
| FFprobe | FFprobeの実行ファイル |
| 字幕フォント | 利用できる日本語フォント。macOS検証では既存のヒラギノ角ゴシック W3を使用 |

フォントの検査値は選択後の保存時に計算されるため、手入力は不要です。音声エンジン・3Dの設定欄は、この段階では空欄で構いません。保存した環境を使う限り、動画ごとの再インストールは不要です。

FFmpeg等をターミナルで確認する場合は `command -v ffmpeg` / `command -v ffprobe` と各 `-version` を使います。Finderから起動するアプリにはターミナルのPATHが引き継がれないため、設定で実行ファイルを指定してください。

## 使う機能だけ追加する

| 使いたい機能 | 追加の準備 |
|---|---|
| 文字・画像・図形・字幕・PSD立ち絵の出力 | 上の基本設定と素材 |
| 合成済みの声やBGMを使う | 作品が参照する音声原本。新しく声を合成しなければTTS不要 |
| セリフを新しく合成する | [使いたい音声エンジンと声](LOCAL_SPEECH_ENGINES.md)だけ。全部のエンジンを入れる必要はない |
| VRMを表示・出力する | モデルと[3D実行環境](DEVELOPMENT.md)。使わなければ不要 |

素材・モデル・フォント・生成音声の条件は[第三者の権利](../THIRD_PARTY.md)を確認してください。

別Macで既存作品を開く場合、JSONだけでは素材が付属しません。元Macで「素材をまとめて保存」を使い、音声・画像・PSDを含めて持ち出してください。

## ソースからビルドする場合だけ

ビルド済みアプリを使う方は、この節を省略します。ソースをGitHubから取得し、`package.json`のあるフォルダーで作業します。

- Xcode Command Line Tools（`xcode-select --install`）
- Node.js 22.22.3 / npm 10.9.8
- rustupと、このリポジトリの`rust-toolchain.toml`で指定したRust
- ビルド時のライセンス文書収集に使うPython 3。

```sh
node scripts/check-toolchain.mjs
npm ci
npm run check
npm test
npm run desktop:bundle
```

`target/release/bundle/macos/Sungeki.app`ができます。初回は依存取得・コンパイルに時間と空き容量が必要です。グローバルのRust設定は変更せず、このプロジェクトのpinを使ってください。[開発手順](DEVELOPMENT.md)も参照してください。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 保存先が使えない | 外部ディスクの接続と実際のマウント名を確認 |
| FFmpeg・FFprobeが見つからない | アプリの設定に各実行ファイルの絶対パスを指定 |
| 字幕を描画できない | 利用可能なフォントを選び直して保存 |
| PSDの未対応機能エラー | 未対応の合成を黙って省略せず停止します。対象PSDと表示されるエラーを確認 |
| 音声エンジンへ接続できない | まず公式アプリで声を利用できるか確認。自動起動にはエンジン実行ファイルを指定 |
| 外部SSDのアクセス確認 | macOSの確認画面でアプリとアクセス先を確認して許可 |

ローカル検証版にはAppleの配布用署名・公証はありません。起動成功、動画出力成功、全機能の受入完了は別の確認です。[検証状況](implementation-status.md)を参照してください。
