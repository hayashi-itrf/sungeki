# Sungeki

Sungekiの読み方は「すんげき」です。

日本語の音声合成と、画像・字幕・立ち絵を組み合わせた動画制作アプリです。GUIとMCPから共通の編集処理を利用できます。

**開発・試用段階です。** 主な動作確認環境はmacOS Apple Siliconです。すべてのモデル・音声エンジン・長時間の音声同期・他OSのGUI動作を保証するものではありません。

## できること

- AivisSpeech / COEIROINKのローカル音声合成（[導入と操作](docs/LOCAL_SPEECH_ENGINES.md)）
- タイムラインで画像・文字・図形・音声・動画・PSD・VRMを配置、編集
- 合成済み音声を使った編集プレビュー、Spaceキーで再生・一時停止
- VRMのモーション・表情・関節ポーズを画面で確認しながら調整
- 字幕、シーン、BGMの音量・フェード・発話中の減音、動画出力
- 作品の保存、Undo/Redo、名前付き保存時点、素材の収集
- MCPによる素材登録・編集・音声合成・動画制作

初期表示はライトテーマです。設定でダークテーマへ切り替えられます。試聴音量はアプリ再起動後も保持します。設定画面のビルド日時・識別番号で起動している版を確認できます。

初めての方は、ツールの準備から説明する[初回導入ガイド](docs/INSTALLATION.md)を参照してください。

## 導入と開発

固定環境はNode.js 22.22.3、npm 10.9.8、Rust 1.98.1です。Rustの指定はこのリポジトリの`rust-toolchain.toml`に従います。macOSではXcode Command Line Toolsが必要です。

```sh
node scripts/check-toolchain.mjs
npm ci
npm run check
npm test
npm run desktop:bundle
```

ローカル検証用アプリは`target/release/bundle/macos/Sungeki.app`に作成されます。通常ビルドはrelease、配布性能確認はdistを使用します。開発時のGUI起動は`npm run desktop:dev`です。

アプリだけですべての音声・映像環境が導入されるわけではありません。動画出力にはFFmpeg/FFprobe、画像処理用Python、利用条件を満たすフォントを用意し、設定から登録してください。音声合成には利用するエンジンとモデル、VRM表示には利用者が用意したVRM/VRMA原本が必要です。

## 初めて使うときの順序（macOSのローカル検証版）

**ビルド済みアプリを受け取った方は、上の開発ツール導入・ビルド手順を実行する必要はありません。** [初回導入ガイドの「ビルド済みアプリから最初の動画を出す」](docs/INSTALLATION.md#ビルド済みアプリから最初の動画を出す)へ進んでください。

動画出力に必要なのは、外部ディスクの保存先、画像処理用Python環境、FFmpeg／FFprobe、フォントの登録です。現在のPython環境準備にはソース一式とNode/npm・uvを使いますが、Rust・`npm ci`・アプリの再ビルドは不要です。音声エンジンは新しく声を合成する場合だけ、3D環境はVRMを使う場合だけ追加します。合成済み音声と素材がそろった作品は、TTSを導入せず出力できます。

現在は手動セットアップが必要な試用版です。別Macでの起動は利用者から報告されていますが、そのMacでの環境準備と動画出力の完了はまだ確認していません。公開インストーラーや全依存の自動導入は未提供です。保存先の外部ディスクは使用中に接続してください。必要容量はモデル・素材・動画尺によって変わります。ローカルビルドはアドホック署名で、Appleの配布用署名・公証は付いていません。
