# Sungeki

Sungekiの読み方は「すんげき」です。

日本語の音声合成と、画像・字幕・立ち絵を組み合わせた動画制作アプリです。GUIとMCPから共通の編集処理を利用できます。

**開発・試用段階です。** 主な動作確認環境はmacOS Apple Siliconです。すべてのモデル・音声エンジン・長時間の音声同期・他OSのGUI動作を保証するものではありません。

## できること

- AivisSpeech / COEIROINKのローカル音声合成（[導入と操作](docs/LOCAL_SPEECH_ENGINES.md)）
- タイムラインで画像・文字・図形・音声・動画・PSD・VRMを配置、編集
- 合成済み音声を使った編集プレビュー、Spaceキーで再生・一時停止
- VRMのモーション・表情・関節ポーズを画面で確認しながら調整
- 字幕、シーン、BGMの音量・フェード・発話中の減音、動画出力
- 作品の保存、Undo/Redo、名前付き保存時点、素材の収集
- MCPによる素材登録・編集・音声合成・動画制作

初期表示はライトテーマです。設定でダークテーマへ切り替えられます。試聴音量はアプリ再起動後も保持します。設定画面のビルド日時・識別番号で起動している版を確認できます。

## 導入と開発

固定環境はNode.js 22.22.3、npm 10.9.8、Rust 1.98.1です。Rustの指定はこのリポジトリの`rust-toolchain.toml`に従います。macOSではXcode Command Line Toolsが必要です。

```sh
npm ci
npm run check
npm test
npm run desktop:bundle
```

ローカル検証用アプリは`target/release/bundle/macos/Sungeki.app`に作成されます。通常ビルドはrelease、配布性能確認はdistを使用します。開発時のGUI起動は`npm run desktop:dev`です。

アプリだけですべての音声・映像環境が導入されるわけではありません。動画出力にはFFmpeg/FFprobe、画像処理用Python、利用条件を満たすフォントを用意し、設定から登録してください。音声合成には利用するエンジンとモデル、VRM表示には利用者が用意したVRM/VRMA原本が必要です。

## 初めて使うときの順序（macOSのローカル検証版）

現在は手動セットアップが必要な試用版です。別のMacでの初回導入全体は未検証で、アプリを置くだけでは動画出力できません。外部ディスクも必要です。公開インストーラーや全依存の自動導入はまだ提供していません。

1. このリポジトリをcloneするかZIPで取得します。privateの間はアクセス権が必要です。ターミナルでソースのフォルダーへ移動し、上記の固定ツールを準備して「導入と開発」のコマンドでアプリを作ります。
2. [画像処理環境の準備](workers/image/README.md)に従い、uv 0.10.6と専用の外部ディスクフォルダーを用意し、`setup:image` → `probe:image`を実行します。ソース一式はこの後も保管してください。
3. [FFmpeg/FFprobe](https://ffmpeg.org/download.html)を別途用意します。「設定」→「動画制作の実行環境」で保存フォルダー、Python環境フォルダー、FFmpeg、FFprobe、利用できる日本語フォントを指定し、保存します。配布アプリの画像処理プログラム欄は空欄で同梱版を使います。
4. まず文字・図形だけの短い作品を作り、「正式な画像を確認」と「動画を書き出す」を試します。これで音声モデルを追加する前に描画環境を確認できます。
5. 音声を使う場合は[音声エンジンの導入と操作](docs/LOCAL_SPEECH_ENGINES.md)に従い、エンジンと声を用意して短いセリフを合成します。モデルごとの規約を確認し、必要なクレジットを作品に記載します。
6. PSD・VRMなどは必要になってから追加します。3D実行環境は[開発ガイド](docs/DEVELOPMENT.md)を参照してください。編集操作は[利用の手引き](docs/USAGE.md)にあります。

保存先の外部ディスクは使用中に接続してください。必要容量はモデル・素材・動画尺によって変わり、生成音声・動画・キャッシュも増えます。OSの許可画面が出たら対象アプリとアクセス先を確認してください。ローカルビルドはアドホック署名で、Appleの配布用署名・公証は付いていません。
