# Sungekiアイコン

`source.png`が原本です。緑色の舞台・幕・再生マークのデザインを、ユーザーが選択しました（2026-10-19）。OpenAIの画像生成ツールで作成した画像で、外部素材やフォントは使用していません。

生成時の指定: 舞台案の形・アイボリー色の記号・緑色を維持。OS側のアイコン枠との二重余白を避けるため、背景を四隅まで塗った不透明の正方形にし、記号を拡大。透明な外周余白や画像内の角丸枠は付けない（2026-10-19修正）。

このプロジェクトのMITライセンスで提供します。

ルートから次のコマンドで各サイズを再生成できます。

```sh
npm run tauri -w @sungeki/desktop -- icon src-tauri/icons/source.png
```

Tauriの生成物には他OS用も含まれますが、対応OSの表明ではありません。macOSアプリは`tauri.conf.json`の`bundle.icon`から`icon.icns`を使用します。
